# Security Policy

PARAMANIACS runs inside Rhino and Grasshopper on people's computers, so we take security seriously, even though the plugin is meant to be fun.

## Supported versions

Only the latest released version receives fixes.

## Reporting a vulnerability or a safety problem

Please **do not** open a public issue for security problems.

Use GitHub's private reporting instead:
**Security tab → "Report a vulnerability"** in this repository.

Report it if you find a component or code that:

- modifies or deletes files, settings or the registry without clear user consent
- makes hidden network connections
- runs automatically or in the background without being asked
- affects anything outside Rhino/Grasshopper
- contains obfuscated or suspicious code

We aim to reply within 7 days and to fix confirmed issues as quickly as possible.

## Release integrity

Official downloads are published only from the **Releases** page of this repository. Please don't install builds from other sources.
